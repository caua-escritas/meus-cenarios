Regras básicas

Visão geral Regras básicas Criação de personagem

Cada teste é uma ação, no estilo roll and keep. Falhar sempre traz algo ruim, então o jogador vai passar, escolher se adaptar, gastar recurso para não perder algo ou se lascar.

Além disso, há o sistema de Destino, ou Pontos de Destino: um recurso que o jogador gasta para ativar algo bom, mas que entrega 1 ponto ao mestre, que pode gastá-lo depois.
